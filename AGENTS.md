# Konektado landing project

Read README.md before significant work. This repository is the standalone public showcase, not the Konektado app or Research backend.

- Keep all runtime assets under public/. Do not add the actual app bundle, account controls, backend code, environment files, API/model secrets, or evaluation data.
- Preserve the supplied wordmark, blue/yellow palette, editorial layout, photo placeholders, English/Taglish copy and explicit fictional prototype labels.
- Keep the same meaning in both languages. Search does not contact providers; requesting a quote is deliberate; normal direct chat follows confirmed booking.
- Keep external app/download links explicit and use the owner-approved build/URL. Do not assume konektado.app is the hackathon app.
- Keep the project dependency-free unless a change requires a package. Use the Node preview; never start Expo.
- Inspect git status before editing and preserve concurrent work. Do not push, publish, change DNS or modify another repository without an explicit request.
- Before code edits, state intended files. Run npm run check and npm test after changes. For UI work, check relevant desktop/phone widths and distinguish browser checks from device tests.
- Retain font/asset licenses. Do not bundle Helvetica binaries without an appropriate webfont license.
